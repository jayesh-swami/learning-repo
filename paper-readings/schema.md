# Paper-Reading-Specific Schema

In addition to the [common fields](../schema.md), paper reviews use the following fields.

| Field | Type | Description |
| :--- | :--- | :--- |
| `authors` | `array[string]` | The authors of the paper. |
| `year` | `integer` | The year the paper was published. |
| `topics` | `array[string]` | Topics or subject areas the paper covers. |
| `related_papers` | `array[string]` | References to other academic papers connected to this one. |
| `related_projects` | `array[string]` | Links to my own small projects related to this paper. |
